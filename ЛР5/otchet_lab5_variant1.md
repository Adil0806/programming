* **Классы модели:**
  * `Link` — описание звена (длина, угол);

  * вывод текущих координат схвата;
  * блокировка значения и вывод предупреждения при выходе угла за допустимые пределы (обработка исключений `try/except`).

## 3. Диаграмма классов

Логика предметной области полностью отделена от графического интерфейса и не импортирует библиотеку `tkinter`.

```text
+-----------------------------------+
|               Link                |
+-----------------------------------+
| + length: float                   |
| + angle: float                    |
+-----------------------------------+
| + __init__(length, angle=0.0)     |
+-----------------------------------+
                  ^
                  | композиция (2 звена)
+-----------------------------------+
|            Manipulator            |
+-----------------------------------+
| + link1: Link                     |
| + link2: Link                     |
+-----------------------------------+
| + __init__(link1, link2)          |
| + forward_kinematics() -> tuple   |
| + __str__() -> str                |
+-----------------------------------+
                  ^
                  | наследование (super())
+-----------------------------------+
|             PlanarArm             |
+-----------------------------------+
| + MIN_A1, MAX_A1: float           |
| + MIN_A2, MAX_A2: float           |
+-----------------------------------+
| + angle1: float (@property)       |
| + angle2: float (@property)       |
+-----------------------------------+
                  ^
                  | агрегация (self.arm)
+-----------------------------------+
|       ManipulatorApp(tk.Tk)       |
+-----------------------------------+
| + arm: PlanarArm                  |
| + canvas: tk.Canvas               |
| + a1_var, a2_var: tk.DoubleVar    |
| + info: tk.StringVar              |
+-----------------------------------+
| + _on_a1(val)                     |
| + _on_a2(val)                     |
| + _reset()                        |
| + _redraw()                       |
+-----------------------------------+
```

### Описание классов

1. **`Link` (Звено).** Хранит геометрическую длину звена в метрах (`length`) и текущий угол поворота в градусах (`angle`).
2. **`Manipulator` (Манипулятор).** Объединяет два звена в кинематическую цепь. Метод `forward_kinematics()` вычисляет декартовы координаты промежуточного сустава $(x_1, y_1)$ и схвата $(x_2, y_2)$:
   $$x_1 = l_1 \cos(lpha_1), \quad y_1 = l_1 \sin(lpha_1)$$
   $$x_2 = x_1 + l_2 \cos(lpha_1 + lpha_2), \quad y_2 = y_1 + l_2 \sin(lpha_1 + lpha_2)$$
   Метод `__str__()` формирует текстовую строку с координатами схвата.
3. **`PlanarArm` (Роборука на плоскости).** Наследует `Manipulator` через вызов `super().__init__()`. Инкапсулирует управление углами с помощью свойств `@property` и сеттеров `@angle1.setter`, `@angle2.setter`, проверяя попадание углов в допустимые пределы суставов (`-90°...90°` для первого звена и `-120°...120°` для второго) с генерацией исключения `ValueError`.
4. **`ManipulatorApp` (Окно приложения).** Наследует `tk.Tk`, строит интерфейс и связывает действия пользователя с методами модели, не выполняя кинематических расчётов внутри виджетов.

## 4. Макет окна приложения и перечень виджетов

### Схема компоновки интерфейса (`grid` и `pack`)

```text
+-----------------------------------+------------------------+
|                                   | [ Панель суставов ]    |
|                                   | Угол Звена 1 (-90..90) |
|         Холст (tk.Canvas)         | [----||--------------] |
|            400 x 400 px           |                        |
|                                   | Угол Звена 2 (-120..120|
|     (оси координат, звенья 1 и 2, | [--------||----------] |
|      точки суставов и схвата)     |                        |
|                                   | [   Сбросить углы    ] |
+-----------------------------------+------------------------+
| Манипулятор: Схват расположен в X=... м, Y=... м | Углы... |
+------------------------------------------------------------+
```

### Перечень используемых виджетов

| Виджет | Назначение в приложении |
| :--- | :--- |
| `tk.Canvas` | Графическое поле размером `400x400` пикселей для отрисовки координатных осей, векторов звеньев (синий и зелёный отрезки) и шарниров. |
| `ttk.LabelFrame` | Контейнер-рамка «Панель суставов» для визуальной группировки элементов управления. |
| `ttk.Scale` | Два ползунка для плавного задания углов поворота первого и второго звеньев манипулятора. |
| `ttk.Label` | Текстовые подписи к ползункам и нижняя строка состояния, связанная с переменной `tk.StringVar`. |
| `ttk.Button` | Кнопка «Сбросить углы» для возврата манипулятора в начальное положение ($0^\circ$). |
| `messagebox.showwarning` | Диалоговое окно предупреждения при попытке установить угол вне допустимого диапазона сустава. |

## 5. Листинг программы

Ниже приведён полный код программы, доработанный с учётом требований методических указаний (добавлена проверка ограничений суставов в `PlanarArm`, перехват ошибок `try/except`, документация `docstring` и комментарии):

```python
import math
import tkinter as tk
from tkinter import ttk, messagebox


class Link:
    """Модель одного звена манипулятора."""

    def __init__(self, length, angle=0.0):
        self.length = length
        self.angle = angle


class Manipulator:
    """Базовая модель двухзвенного манипулятора на плоскости."""

    def __init__(self, link1, link2):
        self.link1 = link1
        self.link2 = link2

    def forward_kinematics(self):
        """Расчёт прямой задачи кинематики (координаты сустава и схвата)."""
        r1 = math.radians(self.link1.angle)
        r2 = math.radians(self.link1.angle + self.link2.angle)
        x1 = self.link1.length * math.cos(r1)
        y1 = self.link1.length * math.sin(r1)
        x2 = x1 + self.link2.length * math.cos(r2)
        y2 = y1 + self.link2.length * math.sin(r2)
        return x1, y1, x2, y2

    def __str__(self):
        """Строковое представление текущего положения схвата."""
        _, _, x2, y2 = self.forward_kinematics()
        return f"Манипулятор: Схват расположен в X={x2:.2f} м, Y={y2:.2f} м"


class PlanarArm(Manipulator):
    """Плоский манипулятор с конструктивными ограничениями углов суставов."""

    LIMIT_1 = (-90.0, 90.0)
    LIMIT_2 = (-120.0, 120.0)

    def __init__(self, link1, link2):
        super().__init__(link1, link2)

    @property
    def angle1(self):
        return self.link1.angle

    @angle1.setter
    def angle1(self, val):
        low, high = self.LIMIT_1
        if not (low <= val <= high):
            raise ValueError(f"Угол звена 1 должен быть в пределах {low}°...{high}°")
        self.link1.angle = val

    @property
    def angle2(self):
        return self.link2.angle

    @angle2.setter
    def angle2(self, val):
        low, high = self.LIMIT_2
        if not (low <= val <= high):
            raise ValueError(f"Угол звена 2 должен быть в пределах {low}°...{high}°")
        self.link2.angle = val


class ManipulatorApp(tk.Tk):
    """Главное окно графического интерфейса управления манипулятором."""

    SCALE = 80   # масштабирование: пикселей на 1 метр
    SIZE = 400   # размер стороны квадратного холста, пикс.

    def __init__(self, arm):
        super().__init__()
        self.arm = arm
        self.title("Управление двухзвенным манипулятором")
        self.resizable(False, False)

        # Связанные переменные интерфейса
        self.a1_var = tk.DoubleVar(value=arm.angle1)
        self.a2_var = tk.DoubleVar(value=arm.angle2)
        self.info = tk.StringVar()

        self._build_widgets()
        self._redraw()

    def _build_widgets(self):
        """Создание и размещение виджетов на главном окне."""
        self.canvas = tk.Canvas(self, width=self.SIZE, height=self.SIZE, bg="white")
        self.canvas.grid(row=0, column=0, padx=10, pady=10)

        panel = ttk.LabelFrame(self, text="Панель суставов")
        panel.grid(row=0, column=1, sticky="n", padx=10, pady=10)

        # Ползунки заданы чуть шире рабочих пределов для демонстрации блокировки
        controls = [
            ("Угол Звена 1 (от -90 до 90):", self.a1_var, self._on_a1, "-90°      0°      90°"),
            ("Угол Звена 2 (от -120 до 120):", self.a2_var, self._on_a2, "-120°     0°     120°"),
        ]
        for text, var, cmd, ticks in controls:
            ttk.Label(panel, text=text).pack(anchor="w", padx=5, pady=(5, 0))
            ttk.Scale(panel, from_=-150, to=150, variable=var, command=cmd).pack(fill="x", padx=5)
            ttk.Label(panel, text=ticks, font=("Consolas", 8), foreground="#777").pack(pady=(0, 5))

        ttk.Button(panel, text="Сбросить углы", command=self._reset).pack(fill="x", padx=5, pady=10)
        ttk.Label(self, textvariable=self.info, font=("Arial", 10, "bold")).grid(
            row=1, column=0, columnspan=2, pady=5
        )

    # ----- Обработчики событий -----

    def _on_a1(self, val):
        try:
            self.arm.angle1 = float(val)
        except ValueError as err:
            self.a1_var.set(self.arm.angle1)  # блокировка ползунка на допустимом значении
            messagebox.showwarning("Ограничение сустава", str(err))
        self._redraw()

    def _on_a2(self, val):
        try:
            self.arm.angle2 = float(val)
        except ValueError as err:
            self.a2_var.set(self.arm.angle2)  # блокировка ползунка на допустимом значении
            messagebox.showwarning("Ограничение сустава", str(err))
        self._redraw()

    def _reset(self):
        """Сброс углов звеньев в нулевое положение."""
        self.arm.angle1 = 0.0
        self.arm.angle2 = 0.0
        self.a1_var.set(0.0)
        self.a2_var.set(0.0)
        self._redraw()

    # ----- Отрисовка -----

    def _px(self, x, y):
        """Перевод декартовых координат (м) в экранные координаты холста (пикс.)."""
        c = self.SIZE / 2
        return c + x * self.SCALE, c - y * self.SCALE

    def _redraw(self):
        """Перерисовка осей, звеньев манипулятора и строки состояния."""
        self.canvas.delete("all")
        x1, y1, x2, y2 = self.arm.forward_kinematics()
        p0, p1, p2 = self._px(0, 0), self._px(x1, y1), self._px(x2, y2)

        # Координатные оси
        self.canvas.create_line(0, self.SIZE / 2, self.SIZE, self.SIZE / 2, fill="#eee")
        self.canvas.create_line(self.SIZE / 2, 0, self.SIZE / 2, self.SIZE, fill="#eee")

        # Звенья манипулятора
        self.canvas.create_line(*p0, *p1, width=6, fill="blue", capstyle="round")
        self.canvas.create_line(*p1, *p2, width=4, fill="green", capstyle="round")

        # Шарниры и точка схвата
        for p, color, r in [(p0, "red", 6), (p1, "black", 5), (p2, "magenta", 4)]:
            self.canvas.create_oval(p[0] - r, p[1] - r, p[0] + r, p[1] + r, fill=color)

        self.info.set(f"{self.arm} | Углы: {self.arm.angle1:.1f}°, {self.arm.angle2:.1f}°")


def main():
    """Точка входа в приложение."""
    arm = PlanarArm(Link(1.3), Link(1.0))
    app = ManipulatorApp(arm)
    app.mainloop()


if __name__ == "__main__":
    main()
```

## 6. Результаты работы

Программа протестирована на штатных и граничных режимах работы:

* **Штатный режим (положение $lpha_1 = 30.0^\circ$, $lpha_2 = 45.0^\circ$).** При перемещении ползунков в пределах рабочих диапазонов на холсте корректно отображаются звенья манипулятора, а в нижней строке состояния выводятся вычисленные координаты схвата: `X = 1.90 м, Y = 2.16 м` *(скриншот окна приложения прилагается в отчёте)*.
* **Граничный режим (превышение допустимого угла).** При попытке вывести угол первого звена за пределы $[-90^\circ; 90^\circ]$ или второго звена за пределы $[-120^\circ; 120^\circ]$ свойство `@angle.setter` выбрасывает исключение `ValueError`. Обработчик перехватывает ошибку через `try/except`, возвращает ползунок на границу диапазона и выводит диалоговое окно предупреждения `messagebox.showwarning` без аварийного завершения программы.
* **Режим сброса.** Нажатие кнопки «Сбросить углы» возвращает оба звена в горизонтальное положение ($0^\circ$), при котором координаты схвата равны сумме длин звеньев (`X = 2.30 м, Y = 0.00 м`).
