## 5. Ответы на контрольные вопросы
1. **В чём разница между локальным репозиторием Git и удалённым репозиторием GitHub?**  
   Локальный репозиторий представляет собой скрытую директорию `.git` непосредственно на компьютере разработчика, где хранится вся история коммитов и веток. Удалённый репозиторий размещается на внешнем сервере (GitHub) и служит для резервного копирования, совместной работы и публикации результатов.
2. **За что отвечают команды `git add` и `git commit`? Какова последовательность их применения?**  
   Команда `git add` добавляет изменённые или новые файлы в область подготовленных файлов (индекс / Staging Area), формируя состав будущего снимка. Команда `git commit` сохраняет подготовленные изменения в историю локального репозитория с текстовым комментарием. Сначала всегда выполняется `git add`, а затем — `git commit`.
3. **Что делает команда `git push`?**  
   Команда `git push` отправляет зафиксированные локальные коммиты из текущей ветки компьютера в связанный удалённый репозиторий на GitHub, синхронизируя их состояния.
4. **Зачем нужна команда `git status`?**  
   Команда `git status` отображает текущее состояние рабочей директории и индекса: показывает, какие файлы были изменены, какие подготовлены к коммиту, а какие ещё не отслеживаются системой Git (`Untracked`).
