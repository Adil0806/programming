## 2. Формулировка индивидуального задания
**Вариант 1. Вибродиагностика подшипников качения турбоагрегата.**

При выходе ротора газовой турбины на рабочий режим из-за износа подшипников возникает повышенная вибрация (мм/с). Высокочастотные помехи от датчиков приводят к кратковременным ложным выбросам, которые перед спектральным анализом необходимо отфильтровать.

**Задачи пользовательского модуля (`variant1_mod.py`):**
1. `filter_outliers(vibe_list, min_val=0.0, max_val=50.0)` — отбраковывает замеры виброскорости вне допуска списковым включением.
2. `get_stat_dict(vibe_list)` — вычисляет среднее, минимум, максимум, объём выборки, возвращая словарь.
3. `extract_top_vibes(vibe_list, k=3)` — сортирует список по убыванию и срезом `[:k]` извлекает `k` пиков.

**Требования к главному скрипту (`main.py`):**
* Считать предел фильтрации из `sys.argv[1]` (значение по умолчанию `45.0`).
* Задать список замеров с выбросами, вызвать функции модуля и вывести сводный отчёт в консоль.

## 3. Описание архитектуры и файлов проекта
Программный комплекс разделён на два файла, размещённых в одной рабочей директории (`lab3/`):

```text
lab3/
├── variant1_mod.py   # Пользовательский модуль с функциями обработки телеметрии
└── main.py           # Главный исполняемый скрипт с чтением sys.argv и выводом отчёта
```

1. **Модуль `variant1_mod.py`:**
   * Содержит три функции с документацией (`docstrings`) для фильтрации аномальных выбросов, расчёта статистических метрик в виде словаря (`dict`) и выделения пиковых значений с помощью сортировки и среза `[:k]`.
   * Включает блок автономного тестирования `if __name__ == '__main__':`, который выполняется только при прямом запуске модуля и не срабатывает при его импорте в главный скрипт.
2. **Главный скрипт `main.py`:**
   * Импортирует функции модуля конструкцией `from variant1_mod import ...`.
   * Считывает верхний порог виброскорости из аргументов командной строки `sys.argv[1]` с резервным значением `45.0` по умолчанию.
   * Формирует исходный массив замеров с ложными выбросами (`-99.0` и `520.0`), выполняет обработку, извлекает последние 3 отсчёта срезом `[-3:]` и выводит структурированный диагностический отчёт.

## 4. Листинг программы

### 4.1. Код пользовательского модуля (`variant1_mod.py`)
```python
# variant1_mod.py
"""Модуль вибродиагностики подшипников качения турбоагрегата."""


def filter_outliers(vibe_list, min_val=0.0, max_val=50.0):
    """Отбраковывает замеры виброскорости вне заданного диапазона."""
    cleaned = [x for x in vibe_list if min_val <= x <= max_val]
    return cleaned


def get_stat_dict(vibe_list):
    """Вычисляет количество, среднее, минимум и максимум выборки."""
    if not vibe_list:
        return {'count': 0, 'mean': 0.0, 'min': 0.0, 'max': 0.0}

    mean_val = sum(vibe_list) / len(vibe_list)

    return {
        'count': len(vibe_list),
        'mean': round(mean_val, 3),
        'min': min(vibe_list),
        'max': max(vibe_list)
    }


def extract_top_vibes(vibe_list, k=3):
    """Сортирует замеры по убыванию и извлекает k максимальных пиков."""
    sorted_vibes = sorted(vibe_list, reverse=True)
    top_k = sorted_vibes[:k]
    return top_k


if __name__ == '__main__':
    # Блок автономного тестирования модуля
    test_raw = [12.4, 15.1, -99.0, 18.2, 520.0]
    filtered = filter_outliers(test_raw, 0.0, 50.0)
    stats = get_stat_dict(filtered)
    top_vibes = extract_top_vibes(filtered, k=3)

    print(f"[Автотест модуля] Отфильтрованный сигнал: {filtered}")
    print(f"[Автотест модуля] Статистика: {stats}")
    print(f"[Автотест модуля] ТОП-3 пика: {top_vibes}")
```

### 4.2. Код главного исполняемого скрипта (`main.py`)
```python
# main.py
import sys
from variant1_mod import extract_top_vibes, filter_outliers, get_stat_dict


def main():
    # Чтение верхнего предела фильтрации из sys.argv (по умолчанию 45.0)
    max_limit = float(sys.argv[1]) if len(sys.argv) > 1 else 45.0

    # Исходный массив замеров виброскорости с ложными выбросами
    raw_sensor_data = [12.4, 15.1, -99.0, 18.2, 520.0, 22.0, 41.5, 14.8, 48.0, 19.3]

    # Вызов функций пользовательского модуля
    clean_data = filter_outliers(raw_sensor_data, min_val=0.0, max_val=max_limit)
    stats = get_stat_dict(clean_data)
    recent_samples = clean_data[-3:]

    # Вывод сводного отчёта в консоль
    print(f"=== ВИБРОДИАГНОСТИКА ПОДШИПНИКОВ ({sys.argv[0]}) ===")
    print(f"Предел фильтрации (sys.argv): {max_limit} мм/с")
    print(f"Очищенная выборка: {clean_data}")
    print(f"Последние 3 замера (срез): {recent_samples}")

    print("Статистика:")
    for key, val in stats.items():
        print(f"  - {key}: {val}")

    top_vibes = extract_top_vibes(clean_data, k=3)
    print(f"ТОП-3 критических пика (срез [:3]): {top_vibes}")


if __name__ == '__main__':
    main()
```
