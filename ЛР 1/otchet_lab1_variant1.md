## 2. Формулировка индивидуального задания

Написать скрипт на языке Python в среде разработки Visual Studio Code, вычисляющий физическую величину по формуле:

$$F = G \cdot \frac{m_1 \cdot m_2}{r^2}$$

**Требования к реализации:**
* Динамически привязать все переменные к вводимым с клавиатуры числовым значениям (`float(input(...))`).
* Вычислить силу гравитационного притяжения $F$ по заданным исходным параметрам (константам варианта 1):
  * гравитационная постоянная $G = 6.674 \cdot 10^{-11}\text{ Н}\cdot\text{м}^2/\text{кг}^2$;
  * масса первого тела $m_1 = 5.97 \cdot 10^{24}\text{ кг}$;
  * масса второго тела $m_2 = 7.34 \cdot 10^{22}\text{ кг}$;
  * расстояние между телами $r = 3.84 \cdot 10^{8}\text{ м}$.
* Осуществить вывод результата строго с помощью `f`-строк с округлением вещественной части до 4 знаков после запятой (`{F:.4f}`).

---

## 3. Описание логики работы программы

Программа представляет собой линейный вычислительный скрипт и состоит из трёх последовательных этапов:

1. **Ввод исходных данных.** С помощью встроенной функции `input()` программа запрашивает у пользователя значения четырёх физических параметров (`G`, `m1`, `m2`, `r`). Функция `float()` преобразует введённые строки (включая запись в экспоненциальной научной нотации вида `6.674e-11`) в числа с плавающей точкой.
2. **Расчёт физической величины.** Вычисление силы гравитационного притяжения выполняется по закону всемирного тяготения Ньютона с использованием арифметических операторов умножения (`*`), деления (`/`) и возведения в степень (`**`). Круглые скобки задают приоритет операций.
3. **Форматированный вывод.** С помощью форматированного строкового литерала (`f`-строки) и спецификатора формата `:.4f` итоговое значение силы выводится в консоль с точностью до четырёх знаков после запятой.

---

## 4. Листинг программы

```python
# lab1_variant1.py
# Лабораторная работа №1. Вариант 1: Расчёт силы гравитационного притяжения

print("=== Расчет силы гравитационного притяжения ===")

# Ввод исходных физических величин с приведением к вещественному типу float
G = float(input("Введите гравитационную постоянную G (например, 6.674e-11): "))
m1 = float(input("Введите массу первого тела m1 в кг (например, 5.97e24): "))
m2 = float(input("Введите массу второго тела m2 в кг (например, 7.34e22): "))
r = float(input("Введите расстояние r в метрах (например, 3.84e8): "))

# Расчёт силы гравитационного притяжения по формуле F = G * (m1 * m2) / r^2
F = G * (m1 * m2) / (r ** 2)

# Форматированный вывод результата с округлением до 4 знаков после запятой
print(f"\nРезультат расчета:")
print(f"Сила гравитационного притяжения F = {F:.4f} Н")
```
